## Question

位置与诊断映射的 MVP 边界：

- 断言失败报告中的"原文件位置"如何获得：转译产物内嵌位置注释 / 元数据表？Testing 模块打印时从哪取？
- 转译产物的编译错误如何指回原文件行列（syntax-transpiler.md 6.3 的两个候选：产物内注释 vs sidecar 映射表）；MVP 是否接受"转译期诊断精确 + 产物错误人工对照"？
- 报告与诊断格式对齐 jai 编译器风格（`file:line,col:`）的程度。

## Resolution

（2026-10-13 grilling 两轮 6 问，票主逐条按推荐拍板）

1. **坐标策略 = 行号保真排版**：视图每行与原文件行一一对应；全部编辑类可保行——test 头一行改一行（`test "x" {` → `juice_test_N :: () -> () {`）、in-package `#load` 剥离行换等行数占位、`@test` 附闭括号同行、视图无头部注释。视图与原文件 1:1（无多文件拼接：E2 符号程序级可见，剥离不内联）。效果：`#caller_location` 的行:列在逐字区（用户断言所在处）即原文件坐标，**零映射**——syntax-transpiler.md 6.3 的「产物内嵌注释 vs sidecar 映射表」两候选**双双不需要**。代价转嫁 0011：排版规范以行号保真为硬约束（可读性让位）。
2. **断言位置来源 = `#caller_location` + driver 注入显式路径映射表**：driver（生成视图者，知道每视图原路径）把「视图绝对路径 ↔ 原包相对路径」字符串对表作为编译期数据写入自身，`#run` 执行清单**之前**注入 Testing；Testing 打印失败时查表精确匹配改写路径，行列原样输出。表是字符串对数组（仅依赖 Basic）；不注入即透传——不破「仅依赖 Basic」与「模型中立」（E5/E9 中立性）。否决单前缀/模式匹配（0008 hash 目录每包/每文件两可、Testing 硬编码缓存布局，皆脆）。
   - 实现期验证项（仿 0008 边界条目先例，spec 写明）：`#caller_location` 的 `file` 串是否与 driver `#load` 传入路径串逐字符一致；若不一致，退化策略 = 前缀+后缀匹配。
3. **产物编译错误回指 = MVP 人工对照**：转译器自身诊断（非法 test 位置、循环加载等）精确引用原文件；jai 编译视图的错误行:列与原文件一致（承决议 1），路径含 `target/transpile/<hash>/` 前缀由人工剥（路径尾段即包相对路径）。juice 侧输出改写（解析 jai 输出剥前缀再透传）列为可加扩展——实施需修订 0006「原样透传」，MVP 不做。
4. **报告格式 = 位置语法对齐 jai 编译器，词汇不对齐**：失败行 `src/foo.jai:57,32: expect_eq failed: expected 3, got 5`（`path:line,col` 前导语法与编译器一致，编辑器/终端点击语义一致；不用 `Error:` 前缀——那是编译器错误行词汇）；每测试开始行 `[test] <报告名>`（匿名报告名本就含 `路径:行号`）；`finish()` 汇总一行 `N passed, M failed`。地图雾项「Testing 失败报告的确切措辞与格式」据此收口，不再毕业成票。
5. **行号保真编辑细则（0011 的硬约束输入）**：剥离的 in-package `#load` 行 → 单行注释占位（`// juice: load stripped` 类；语句占 K 行补 K 行，常态 K=1，Jai 字符串不跨行）；`@test` 附闭括号同行（`}` → `} @test`，E9 验证形态）；视图零头部注释——溯源元数据只在 driver 映射表，可选 EOF 尾注标记由 0011 定夺；列保真承诺仅限逐字区，编辑行（test 头、占位行）列不承诺——断言不可能落在编辑行，落在其上的编译错误人眼对照时列可能偏移，接受。
6. **ADR 挂 0011**：行号保真过三条件（难逆：改掉需整套映射表机制+重做 golden；无上下文会困惑：视图占位注释行；真权衡：可读性 vs 零映射坐标），但它是 0011 排版规范的核心承诺、golden 是其锁定机制——决议记本票，《视图行号保真》ADR 与排版规范在 0011 session 一处决策一处成文。

词汇候选（0010 收口，已附补充输入）：Test view 词条写明行号保真承诺及边界；「转译期诊断精确、产物诊断人工对照」边界句并入 Test view 或 Transpile 词条；不单设「位置映射」词条（内部机制，非命令语言词汇）。
