# 0005: 视图行号保真——转译产物与源文件行号一一对应，可读性让位

test block 不是合法 Jai，测试视图是 test 语法编译的必经产物，而断言失败报告、编译错误的坐标都出在视图上。若视图按可读性重排版，行号即漂移，必须引入整套位置映射机制（产物内嵌注释或 sidecar 表）才能把坐标映回原文件；若视图每行与原文件一一对应，`#caller_location` 的行:列在逐字区（用户断言所在处）即原文件坐标——**零映射**。本 ADR 把行号保真立为视图排版的硬约束，可读性让位；代价与细则由 [转译产物排版规范](../transpiled-output-formatting.md) 承接（与本 ADR 一并成文，0011 号票）。

**决定**：

1. **行号保真为最高约束**：任何视图（测试视图与剥离视图）的行数都与原文件严格一致，任何编辑都以「1 行换 1 行」为单位展开；无法等行数展开的输入形态在转译期拒绝（如多行 test 头）。可读性（重排版、注释头、空行整理）一律让位。
2. **逐字区 + 编辑点**：视图 = 逐字区与编辑点交错。除编辑点外的全部文本（注释、空白、token 间 trivia）以「行内容逐字节」保留（行尾统一规范化为 `\n`）；编辑点以 token 为界，仅三类——test 头替换（`juice_test_N :: () -> () {`）、`@test` 注记（贴闭括号后）、in-package `#load` 剥离 / build 剥离的等行数注释占位。视图无头部/尾部注记。
3. **build 剥离同样保行**：0008 号票「剥离视图（删 test block）」中的「删」为语义删除——test block 不再进入编译，物理形态是等行数注释占位（`// juice: test stripped`），剥离视图与测试视图共享 1:1 不变量（修订 ADR 0004 决定 1 的物理形态措辞）。
4. **列保真仅限逐字区**：编辑行（test 头行、占位行）的列不承诺；断言不可能落在编辑行上，编辑行上的编译错误由人工对照、列可能偏移（0009 号票已接受）。
5. **golden 为锁定机制**：排版规范的全部细则（占位文本、`@test` 位置、行尾、driver/first.jai 模板）由 golden 基线逐字节锁定；规范演进以基线更新为证（`JUICE_UPDATE_GOLDEN` 重写 + 人工审阅 diff），防止无意的排版漂移。

**Considered Options**: (a) 行号保真排版（选中）——零映射坐标，代价是产物可读性；(b) 重排版可读优先 + 位置映射表（syntax-transpiler.md 6.3 的 sidecar 候选）——否决：整套映射机制 + 查表路径，且断言行号要过表还原；(c) 产物内嵌位置注释——否决：注释占用原行位置、破坏可读性且需解析。0009 号票判定本决策满足 ADR 三条件（难逆：改掉需重做映射机制与全部 golden；无上下文会困惑：占位注释行；真权衡：可读性 vs 零映射）。

**Consequences**: 视图不可读性上升（占位注释行、生成过程头），人工对照视图时以原文件为主；未来任何 test 语法特性若无法等行数展开，即被排版规范拒绝或需修订本 ADR；golden 基线成为规范的强制证据，演进需同步更新基线；`juice_test_` 前缀保留给转译器，用户符号撞前缀由 jai 重定义错误自然暴露（MVP 不规避）。
